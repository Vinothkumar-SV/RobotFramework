# 🚀 Robot Framework Automation Project

## 📌 Overview  
This project is a **Robot Framework based automation framework** designed for UI testing using **SeleniumLibrary**.  
It demonstrates real-time test automation scenarios like login, navigation, and form handling.

---

## 🧰 Tech Stack  
- 🤖 Robot Framework  
- 🌐 SeleniumLibrary  
- 🐍 Python  
- 🌍 Chrome Browser  
- 🧪 Test Automation (UI आधारित)

---

## 📁 Project Structure  

RobotFramework/
│
├── tests/                # Test cases
├── resources/            # Reusable keywords (if added)
├── variables/            # Test data (optional)
├── reports/              # Execution reports
└── README.md

---

## ⚙️ Prerequisites  

Before running this project, make sure you have:

- ✅ Python (3.x) installed  
- ✅ pip installed  
- ✅ Google Chrome browser  
- ✅ ChromeDriver (matching browser version)  

---

## 📦 Installation  

### 1. Clone the Repository  
git clone https://github.com/Vinothkumar-SV/RobotFramework.git  
cd RobotFramework  

### 2. Install Required Libraries  
pip install robotframework  
pip install robotframework-seleniumlibrary  

---

## ▶️ Steps to Run  

### Run all test cases  
robot tests/  

### Run a specific file  
robot tests/your_test_file.robot  

---

## 📊 Reports Generated  

After execution, Robot Framework generates:

- 📄 report.html → Execution summary  
- 📄 log.html → Detailed logs  
- 📄 output.xml → Raw execution data
